## Material findings
1. Deployment drift: live tournaments table lacked series_id and season_number expected by local season-related work. GitHub synchronization does not establish database migration deployment.
2. Series routes/forms/filters exist, but use tournament-category storage and shared lifecycle. Best-of-N early-clinch lifecycle is incomplete.
3. Premature-Q prevention is not an exhaustive mathematical qualification engine (#328).
4. Player-setting RPC exists; populated live player correction UI needs work.
5. Historical admin edits/recompute exist; scorer approvals, immutable correction revisions and previews remain incomplete.
6. Streaming is gated, payments are test/prepared, and device/provider workflows need actual integration tests.
7. Offline retry/idempotency does not equal multi-device conflict resolution.
8. DLS helper is approximate; not an official complete DLS engine.
