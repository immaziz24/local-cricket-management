# Statistics definitions (batch 9, #79–#102 and #345–#356)

Every statistic is worked out from the scored balls each time it is shown. Nothing is stored separately, so a corrected ball (batch 8) changes every figure straight away. Super overs are never counted in player statistics. Matches counted: live, completed and abandoned.

| Figure | How it is worked out |
|---|---|
| Runs (#79) | Sum of runs off the bat by the batter. Wides, byes, leg byes and penalties are not the batter's runs. |
| Balls faced | Every ball faced except wides. A no-ball counts as a ball faced. |
| Batting average (#80) | Runs divided by (innings − not outs). Blank when never out. Retired hurt is not out; retired out is out. |
| Strike rate (#81) | Runs × 100 / balls faced. |
| Fours and sixes (#82) | Balls where the batter scored exactly 4 or exactly 6 off the bat. |
| Highest score (#83) | Best single innings; on a tie the not-out one wins. |
| 50s / 100s (#84, #85) | 50–99 counts as a fifty; 100 or more counts as a hundred (not also a fifty). |
| Wickets (#86) | Bowled, caught, LBW, stumped, hit wicket, caught and bowled. Run-outs and retirements are not the bowler's. |
| Bowling average (#87) | Runs conceded / wickets. |
| Economy (#88) | Runs conceded × 6 / legal balls. |
| Bowling strike rate (#89) | Legal balls / wickets. |
| Best bowling (#90) | Most wickets; fewest runs on a tie. |
| Runs conceded | Runs off the bat plus wides and no-balls. Byes and leg byes are not charged to the bowler. |
| Maidens (#91) | A full over of 6 legal balls with no runs off the bat and no wides or no-balls. An over shared by two bowlers is not a maiden for either. |
| Dot balls (#92) | Legal balls with no run off the bat (byes and leg byes still count as dots for the bowler). |
| Catches (#93) | Fielder on a caught dismissal; the bowler on caught and bowled. |
| Run-outs, stumpings (#94, #95) | The fielder named on the dismissal. |
| MVP points (#97) | 1 per run, +1 per four, +2 per six, +8 for 50, +24 for 100, 25 per wicket, 8 per maiden, 1 per dot ball, 8 per catch, 12 per stumping, 10 per run-out. |
| Player of the Match (#96) | Highest MVP points, picked automatically at the end; the scorer can override it. |
| Boundary tracker (#355) | Fours, sixes and boundary runs from balls with exactly 4 or 6 off the bat, by team, player and phase of the innings. |
| Statistics check (#356) | Per innings: scoreboard runs = batters' runs + extras + penalties = runs charged to bowlers + byes/leg byes + penalties; wickets and legal balls also match the balls. Shown on every match's Analysis tab. |
