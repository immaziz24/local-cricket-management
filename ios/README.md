# Cricnotch iOS

On a Mac with Xcode and XcodeGen installed, run `xcodegen generate` from this directory and open the generated `Cricnotch.xcodeproj`. Select an iOS simulator and run the app. To install on an iPhone, choose a signing team in Xcode.

The first build loads the shared Cricnotch site. Check launch, sign-in, navigation, and opening external links on the simulator before distributing it.
